# 🎬 MovieTracker

MovieTracker is a simple web app built with **React** and **JavaScript** that lets users:

- ✅ Track movies they’ve watched
- 🔍 Search for any movie using a public API (e.g., OMDb or TMDB)
- 📦 Store movie data in a database

---

## 🚀 Features

- Add movies you've watched
- Mark movies as watched/unwatched
- Search movies via external movie API (like OMDb or TMDB)
- Save movie data to a backend/database
- Responsive UI with React

---

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript, HTML/CSS
- **API:** OMDb API / TMDB API
- **Backend:** (optional, e.g., Node.js, Firebase, Express)
- **Database:** (optional, e.g., MongoDB, PostgreSQL, Firebase)
